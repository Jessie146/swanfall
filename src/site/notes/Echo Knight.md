The **Echo Knight** specialises in the remnants left behind by dimensional travel. Every time a Riftblade tears through space, a fragment of their movement remains behind. Echo Knights have learned to give these fragments temporary physical form.

These **Echoes** appear as translucent copies of the Riftblade, capable of performing limited attacks and interacting with the battlefield. An Echo Knight may therefore appear to be fighting in several places at once.

#### Echo Knight Mechanics

##### Echoes

Echo Knights can create temporary **Echoes** on the battlefield. Each Echo occupies a tile and can perform a limited number of actions before disappearing.

Echoes can:

- Repeat attacks.
- Occupy tiles.
- Flank enemies.
- Trigger certain abilities.
- Serve as teleportation points.
- Disappear to create another Echo elsewhere.

##### Echo Chain

Attacks performed by an Echo can create additional echoes or empower the next attack performed by the Riftblade. This allows an Echo Knight to create a chain of attacks across several tiles.

#### Signature Abilities

**[[Manifest Echo\|Manifest Echo]]**

Create a dimensional copy of the Echo Knight on a nearby tile. The Echo remains for several turns and can perform basic attacks.

**[[Echoing Strike\|Echoing Strike]]**

Command an Echo to repeat the Riftblade's most recent attack.

**[[Rift Exchange\|Rift Exchange]]**

Swap positions with an Echo. The original position is briefly torn open, damaging nearby enemies.

**[[Many Blades\|Many Blades]]**

Every active Echo performs a copy of the Riftblade's current attack against enemies within its range.

**[[Infinite Reflection\|Infinite Reflection]]**

Create several Echoes around the battlefield. For a short duration, attacks made by the Riftblade are repeated by each active Echo. When the effect ends, all remaining Echoes collapse into a single dimensional explosion.
